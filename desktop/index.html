APPENDHUB PRODUCT

AppendHub Desktop

An experimental, terminal-first desktop session for Debian 13, built with Bash, Kitty, Openbox, GTK 3, and X11 utilities.

PUBLIC BETA · v0.6.0

Public beta

AppendHub Desktop is still under development. Bugs and unexpected behavior may occur. Upstream documentation targets Debian 13 with X11; other environments have not been verified, and this integration has not independently tested a full installation. Back up important files before installation and review the requirements and installer first.

What it includes

  • Run regular shell commands and launch installed graphical applications from a terminal-first session.
  • List and focus application windows; minimized windows are shown in a small GTK bar.
  • Preview an application removal and explicitly confirm before the tool runs apt remove.
  • Choose Kitty color themes, including the AppendHub royal-purple palette.
  • Check configured GitHub releases and verify a SHA-256 checksum before explicitly confirming an update.

Requirements

Debian 13 with an X11 session is the documented target, not an independently verified compatibility guarantee. Required runtime programs and Python GTK bindings are checked by the installer. Other distributions, desktop managers, hardware, and architectures have not been verified.

Installation

Review the source archive and install.sh before running it. The installer uses sudo to register a display-manager session and install its launcher. It does not remove your existing desktop, preserves an existing shell configuration, and currently has no uninstaller. Log out and choose AppendHub Desktop (Public Beta) from the session selector; keep your current desktop available as a fallback.

Install the documented dependencies on Debian 13:

sudo apt update
sudo apt install --no-install-recommends git kitty openbox libgtk-3-bin python3 python3-gi gir1.2-gtk-3.0 wmctrl x11-utils unzip
