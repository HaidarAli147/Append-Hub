APPENDHUB PRODUCT

Append TDX

A terminal-first Linux desktop session for Debian 13, featuring a dedicated GTK/VTE terminal desktop surface, Openbox window management and optional taskbar.

EXPERIMENTAL · SOURCE UPDATE AVAILABLE

Public beta

AppendHub Desktop is still under development. Bugs and unexpected behavior may occur. Upstream documentation targets Debian 13 with X11; other environments have not been verified, and this integration has not independently tested a full installation. Back up important files before installation and review the requirements and installer first.

Latest Append TDX features

The current source on GitHub includes an integrated terminal desktop surface built with GTK 3 and VTE, replacing the earlier fullscreen Kitty window. Openbox manages ordinary Linux application windows above the desktop.

  • Use /settings for terminal-based system settings, /wifi for NetworkManager networks, and /volume for audio controls.
  • Handle Prt Sc screenshot capture through Append Capture, with selection and annotation through Flameshot.
  • Session-specific volume up/down, mute and brightness key bindings are included. Hardware behavior still needs testing on real machines.
  • Enable the upgraded royal-purple taskbar with /taskbar add, or remove it with /taskbar remove. It includes application buttons, a clock and system tray.
  • Run update tdx from an installed Append TDX terminal to check GitHub and request confirmation before installing a source update.
  • Open graphical applications from the terminal and use standard Linux shell commands.

Version distinction: the downloadable v0.6.0 ZIP below is an older archival beta and does not contain all these updates. Use the latest GitHub source for new functionality. The current source has passed automated syntax checks, but full desktop startup and hardware keys have not yet been independently verified on the target laptop.

Requirements

Debian 13 with an X11 session is the documented target, not an independently verified compatibility guarantee. Required runtime programs and Python GTK bindings are checked by the installer. Other distributions, desktop managers, hardware, and architectures have not been verified.

Installation

Review the source archive and install.sh before running it. The installer uses sudo to register a display-manager session and install its launcher. It does not remove your existing desktop, preserves an existing shell configuration, and currently has no uninstaller. Log out and choose Append TDX from the session selector; keep your current desktop available as a fallback.

Install the documented dependencies on Debian 13:

sudo apt update
sudo apt install --no-install-recommends git kitty openbox libgtk-3-bin python3 python3-gi gir1.2-gtk-3.0 wmctrl x11-utils unzip

Source updates

For current development code, see the Append TDX GitHub repository. Once the updater is installed, type update tdx inside Append TDX to check for changes. Review the update confirmation before installing.
