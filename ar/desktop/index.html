AppendHub Desktop

جلسة سطح مكتب تجريبية تعتمد على الطرفية لنظام Debian 13، مبنية باستخدام Bash وKitty وOpenbox وGTK 3 وأدوات X11.

النسخة التجريبية العامة · v0.6.0

تنبيه النسخة التجريبية العامة

أبند هَب ديسكتوب ما زال قيد التطوير. قد تظهر أخطاء أو سلوكيات غير متوقعة أو مشكلات توافق. توثيق المشروع يستهدف Debian 13 مع جلسة X11؛ هذا ليس ضماناً مستقلاً للتوافق ولم نختبر تثبيتاً كاملاً في هذه المراجعة. لم يتم التحقق من توزيعات أو أجهزة أخرى. احتفظ بنسخة احتياطية من ملفاتك المهمة، وراجع المتطلبات والمثبت قبل التثبيت.

الميزات

  • تشغيل أوامر Bash العادية وتشغيل التطبيقات الرسومية المثبتة من جلسة تعتمد على الطرفية.
  • استعراض نوافذ التطبيقات والتنقل بينها وعرض النوافذ المصغّرة في شريط GTK.
  • معاينة إزالة التطبيق قبل التأكيد على تشغيل apt remove.
  • اختيار سمات ألوان Kitty، ومنها اللون الملكي لأبند هَب.
  • التحقق من إصدارات GitHub وفحص SHA-256 قبل تأكيد التحديث يدوياً.

المتطلبات

الهدف المذكور في التوثيق هو Debian 13 مع جلسة X11، ولم يتم التحقق منه هنا بتثبيت فعلي. يتحقق المثبت من البرامج المطلوبة وربط Python مع GTK. لم يتم التحقق من توزيعات أو أجهزة أو معماريات أخرى.

التثبيت

راجع أرشيف المصدر والملف install.sh قبل تشغيله. يستخدم المثبت sudo لتسجيل الجلسة في مدير الدخول وتثبيت المشغّل. لا يحذف سطح المكتب الحالي ويحافظ على إعداد Bash الموجود. لا يوجد حالياً برنامج لإلغاء التثبيت. بعد التثبيت، سجّل الخروج واختر AppendHub Desktop (Public Beta) من قائمة الجلسات، واحتفظ بسطح المكتب الحالي كخيار بديل.

تثبيت المتطلبات الموثقة على Debian 13:

sudo apt update
sudo apt install --no-install-recommends git kitty openbox libgtk-3-bin python3 python3-gi gir1.2-gtk-3.0 wmctrl x11-utils unzip
