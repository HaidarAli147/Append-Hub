# Retro TV presentations

`/projects/retro-tv/presentations/retro-tv-project-fair-deck.pptx`

The project page links to the deck in AppendHub Present and provides a direct download. Add future PowerPoint `.pptx` files to this folder, then add a matching link in the Presentations section of `../index.html`. For the AppendHub Present viewer, pass the public file path as the `ppt` parameter, plus a `title` and `back=/projects/retro-tv/` parameter. The viewer supports this project presentation folder.
